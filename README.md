# 🚀 AI-Powered Growth Auditor

An intelligent analysis tool built to audit content trends, deconstruct storytelling frameworks, and evaluate website copy. It bridges the gap between raw data and actionable Go-To-Market (GTM) strategies, helping founders and growth teams optimize their digital footprint.

## 💡 The Problem It Solves
In a fast-paced ecosystem, manually tracking what makes a startup or creator go viral is inefficient. This application leverages Generative AI to automate the auditing process, providing data-driven insights into audience engagement, readability, and conversion psychology.

## ✨ Core Features
*   **Intelligent Copy Auditing:** Evaluates above-the-fold clarity, conversion psychology, and authority transfer using advanced agency rubrics.
*   **Automated Content Extraction:** Scrapes and processes live web data to analyze real-time market positioning.
*   **LLM-Powered Insights:** Utilizes Google's Generative AI (Gemini) to generate actionable branding and growth recommendations.
*   **Interactive Visualizations:** Renders dynamic data charts to map full-funnel architectures.
*   **Automated Reporting:** Generates downloadable, professional PDF audit reports for stakeholders and clients.

## 🛠️ Tech Stack
*   **Frontend / UI:** [Streamlit](https://streamlit.io/)
*   **AI & NLP:** Google Generative AI (Gemini API), Textstat
*   **Data Processing & Scraping:** BeautifulSoup4 (bs4), JSON, Requests
*   **Data Visualization:** Plotly Graph Objects
*   **Report Generation:** ReportLab

## 🚀 Getting Started

### Prerequisites
*   Python 3.8+
*   A valid Google Gemini API Key

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Harshahv12/ai-powered-growth-auditor--for-websites-.git](https://github.com/Harshahv12/ai-powered-growth-auditor--for-websites-.git)
2. **Navigate to the directory:**  cd ai-powered-growth-auditor--for-websites-
3. **Install required dependencies:** pip install -r requirements.txt
4. **Set up your environment variables:** Create a .env file in the root directory and add GEMINI_API_KEY="your_api_key_here"
5. **Run the application:** streamlit run GrowthAudit.py
